# Content types

Pick the content shape first, then choose nodes. Start with [shape recipes](./recipes.md): weekly report, design explainer, implementation plan, decision, status board.

| Pattern | Use when | Primary nodes |
|---|---|---|
| [Shape recipes](./recipes.md) | Any common page shape | `chapter`, `ledger`, `steps`, `map`, `story`, `compare` |
| [Architecture diagrams](./architecture-diagrams.md) | System topology, module relationships, runtime flows | `map`, `story`, `sequence`, `steps` |
| [Dashboards & metrics](./dashboards.md) | Few numbers, status, health overviews | `figures`, `ledger`, `trend`, `table` |
| [Timelines & roadmaps](./timelines.md) | Sequences of events, phases, milestones | `timeline`, `steps`, `checklist` |
| [Data organization](./data-organization.md) | Tables, comparisons, inventories | `table`, `compare`, `ledger` |
| [Plans](./plans.md) | Implementation plans and RFCs | `claim-tree`, `checklist`, `decision` |
| [Code reviews](./code-reviews.md) | API boundaries and changes | `execution-trace`, `code` |
